# 项目面试准备手册

配套 [面试项目介绍 Beamer](../beamer/project-introduction.pdf) 的个人学习材料。目标是能解释项目背景、画出执行链路、手算核心决策、推演失败场景，并准确说明个人与团队工作。

- [Word学习版](项目面试准备手册-陶壮.docx)：54页，自动目录、原生公式和源码导航。
- [PDF阅读版](项目面试准备手册-陶壮.pdf)：与Word对应的固定排版版本。
- [Markdown完整版](项目面试准备手册-陶壮.md)：便于搜索函数名、问答和源码路径。
- [构建与练习说明](build/README.md)：可维护的Word生成工具和无模型练习。
- `chapters/`：七个分章源稿及Agent边界练习。

| 正文范围 | 内容 | Word/PDF页码 |
|---|---|---|
| 00 阅读地图 | 项目层次、个人边界、证据标签和三轮学习法 | 5—6 |
| 01 推理系统 | OmniInfer、OmniPlacement、Omni-EPLB，静态布局与动态运行时 | 7—17 |
| 02 数据工程平台 | DataHub模型、注册SDK、身份凭证、域权限与Data Agent | 18—24 |
| 03 推理网关 | LiteLLM路由、Redis状态、取消释放与Prometheus回调 | 25—31 |
| 04 Simulator | 事件模型、开闭环、经验后端、指标与反事实边界 | 32—38 |
| 05 编码Agent平台 | Delm看板、异步与持久化、Harness²执行与结果采纳 | 39—49 |
| 06 闭卷模拟 | 跨项目问题、快速自检、1小时模拟及准备程度评分 | 50—54 |

全稿有66组分级主问题（每组再深入两层）、10个项目练习和12项快速自检。先读00和每章开头，练两分钟项目介绍；再沿一个请求或事件追状态，最后闭卷答题并完成练习。面向Agent岗位可提前读第五章。

正文中的作者本机路径、历史提交和源码快照定位保留原学习稿口径；35个本地链接依赖作者工作区，其他机器可按路径中的项目、文件和函数名定位独立取得的源码。源项目、内部系统配置与业务轨迹未随本材料打包。两个Agent探针需要另外提供相应源码目录，其余合成练习不调用模型或生产服务。

状态标签区分已实现、理论/复现、通用知识和改进建议。代码存在不代表全部由个人原创，测试或模拟也不代替真实模型质量和业务性能证据。Word、PDF和Markdown保留已核验正文；发布时仅将工具中的本机依赖改为显式配置。
